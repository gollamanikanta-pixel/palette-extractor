How It Works

1

Pixels → Numbers

Every pixel is 3 numbers (R,G,B). A 150×150 image becomes a table of 22,500 rows — each row is one colour.

2

K-Means Clustering

The algorithm groups pixels with similar RGB values into K clusters — pixels close together in colour space form one group.

3

Cluster Centres

Each cluster centre (average RGB) becomes a palette colour. More pixels in a cluster = higher percentage shown.
